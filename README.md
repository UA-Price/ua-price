# UA 比價卡組

Union Arena 日文版卡牌的比價與卡組編輯網站，電腦和手機都能用。

- **比價**：遊々亭、Hobby Station、Dorasuta 三家價格並排，標出每張卡最便宜的店
- **匯入**：三家都不讓雲端伺服器自動抓價，所以用書籤「UA 匯入價格」在你自己的瀏覽器裡讀取，讀完自動同步到手機
- **卡組**：自動算總價、規則檢查（50 張／同卡號 4 張／同作品）、匯出清單或圖片、多副卡組

---

## 第一次架設

### 1. 註冊 GitHub
到 https://github.com 註冊免費帳號。

### 2. 建立專案
右上角 **＋** → **New repository** → 名稱填 `ua-price`、選 **Public** → **Create repository**

### 3. 上傳檔案
點 **uploading an existing file**，把 `ua-price` 資料夾**裡面**的所有檔案和資料夾拖進去 → **Commit changes**

> `.github` 資料夾目前用不到（裡面是伺服器抓價程式，被遊々亭擋了），沒傳上去也沒關係。

### 4. 開啟網站
**Settings** → 左側 **Pages** → **Branch** 選 `main`、`/ (root)` → **Save**
等 1～2 分鐘，上方會出現網址，例如 `https://你的帳號.github.io/ua-price/`

### 5. 設定書籤與同步（在電腦上做一次）
用電腦打開網站 → **匯入・設定** 分頁：
1. 把「UA 匯入價格」按鈕**拖曳**到 Chrome 書籤列（`Ctrl + Shift + B` 打開書籤列）
2. 照「自動同步到手機」裡的步驟建立 GitHub 金鑰，貼上後按 **儲存並測試**

### 6. 第一次匯入（先從遊々亭開始）
1. 打開遊々亭的 Union Arena 頁面 → 按書籤「UA 匯入價格」→「匯入全部系列」（約 7 分鐘）
2. 再到 Hobby Station、Dorasuta 各做一次（各約 10～15 分鐘）

卡片清單、稀有度、卡圖都來自遊々亭，所以要先匯入遊々亭。

### 7. 手機加到主畫面
- iPhone（Safari）：分享按鈕 → 加入主畫面
- Android（Chrome）：右上角 ⋮ → 加到主畫面

## 平常怎麼用
- 想更新價格時，在電腦上到三家網站各按一次書籤 →「匯入全部系列」，分頁開著就好
- 完成後自動同步，手機 1～2 分鐘後就看得到
- 超過 14 天沒更新的價格會標示「舊」
- 只想更新某個系列：打開那個系列的頁面，按書籤選「只匯入這個系列」

## 常見問題
- **書籤按了沒反應**：瀏覽器可能擋下彈出視窗。網址列右邊出現圖示時，選「一律允許」再按一次。
- **書籤顯示「網站要求重新確認連線」**：重新整理那一頁，等它正常顯示後再按一次書籤。
- **同步失敗、金鑰過期**：到「匯入・設定」重新建立金鑰貼上，再按「立即同步」。
- **商店改版後讀不到**：把畫面截圖給 Claude，修改 `importer.js` 即可。

價格僅供參考，實際以各商店頁面為準。

      價格資料

      一鍵匯入價格（遊々亭・Hobby Station・ドラゴンスター・メルカード・卡拍拍）

      三家都不讓雲端伺服器自動抓價，所以改用書籤：在你自己的瀏覽器裡用正常速度把每個系列讀一遍。請先從遊々亭開始，卡片清單、稀有度和卡圖都來自遊々亭。

      1. 按 Ctrl + Shift + B 打開 Chrome 的書籤列。
      2. 把下面這個按鈕拖曳到書籤列上。
        UA 匯入價格
      3. 打開 遊々亭、Hobby Station 、ドラゴンスター 、メルカード 或 卡拍拍 的 Union Arena 頁面（任何一頁都可以）。
      4. 按書籤列上的「UA 匯入價格」→ 選「匯入全部系列」。
      5. 右下角會顯示進度：遊々亭約 15 分鐘、Hobby Station 約 30 分鐘、ドラゴンスター 約 50 分鐘、メルカード 約 15 分鐘、卡拍拍 不到 1 分鐘（刻意放慢，避免被封鎖）。建議一週最多更新一次。這段時間那個分頁不要關，可以去做別的事。

      第一次按時，Chrome 可能會擋下彈出視窗：網址列右邊出現圖示時，選「一律允許」再按一次書籤。

      卡片顏色・費用：打開 官方卡表，按同一個書籤 →「只抓新作品」。第一次會把全部作品抓一遍（約 30 分鐘），之後有新作品時再按，通常不到 1 分鐘。

      自動同步到手機（GitHub）

      設定後，每次在這台電腦匯入完成，價格會自動存到你的 GitHub 專案，手機打開網站就看得到。只需要在按書籤的那台電腦設定一次。

      尚未設定

      如何建立金鑰（約 2 分鐘）
      1. 打開 GitHub 建立金鑰頁面（Fine-grained token）。
      2. Token name 隨便取，例如「UA 比價同步」；Expiration 選最長的期限。
      3. Repository access 選「Only select repositories」，勾選你的比價網站專案（例如 ua-price）。
      4. Permissions → Repository permissions → Contents 選「Read and write」。
      5. 按最下面的 Generate token，複製 github_pat_ 開頭的那串，貼到下面。

      金鑰只存在這台電腦的瀏覽器裡，而且只能改這一個專案。不要把金鑰傳給別人。

        使用說明

        查價之境可以比較 Union Arena 日文版單卡在遊々亭、Hobby Station、ドラゴンスター、メルカード 的日幣價格，以及台灣玩家交易平台「卡拍拍」的台幣價格（台幣另外顯示、另外算總價，不跟日幣比），也可以直接組卡組、算整副要多少錢。按右上角「換算台幣」可以把日幣價格依當天匯率換算成台幣顯示（標 ≈ 的是換算值），再按一次切回日幣。

        找卡、看價格
        • 上方輸入框可以打卡名或卡號（例：シャイ、SHY-1-046）。
        • 用系列、稀有度、顏色、費用、AP 篩選，顏色和費用可以多選。
        • 排序可以選卡號順、價格便宜→貴、貴→便宜、費用低→高；勾「只看有庫存」會藏起買不到的卡。
        • 每張卡下面是各家價格：綠框＝最便宜、劃線＝售完、「剩 N」＝只剩幾張、「舊」＝超過 14 天沒更新。
        • 左上角會寫價格最後更新的時間。價格只是參考，實際以店家頁面為準。
        點卡片看大圖和各家價格
        • 點一下卡片（＋ 按鈕以外的地方）會跳出大圖，右邊由上到下列出各家價格、庫存。
        • 「前往○○ ↗」會打開那家店的商品頁，看到的就是當下最新的價格；沒有資料的店則是「在○○搜尋」。
        • 視窗下面可以直接增減這張卡在卡組裡的張數。按 ×、點外面、按返回鍵都能關掉。
        組卡組
        • 按卡片右邊的 ＋ 加入目前的卡組。手機到下方「卡組」分頁看，電腦則在右半邊。
        • 規則檢查：主卡組 50 張、同卡號最多 4 張、只能用同一個作品；AP 卡不算在 50 張內。
        • 「全部換成最便宜版本」會把每張卡換成同卡號裡最便宜、有庫存的稀有度。
        • 可以存很多副卡組：新增、改名、複製、刪除都在卡組名稱旁邊。
        測試起手、練習對戰
        • 「測試起手」：洗牌後看起手 7 張，可以換手牌一次、繼續抽牌。
        • 「對戰」分頁（測試中，只有管理端看得到）：選玩家 A、B 的卡組，你一個人輪流操作兩邊。決定先攻 → 雙方換手牌 → 各放 7 張生命，接著照回合流程（起始・移動・主要・攻擊・結束）進行；左邊是玩家 A、右邊是玩家 B 的資訊，中間是目前回合玩家的場地。
        • 起始階段會自動把卡置為活動、放 AP 卡（先攻 1/2/3、後攻 2/2/3 張）、抽 1 張（先攻第 1 回合不抽）。
        • 手牌可以直接拖到場上登場、拖到角色上突襲、拖到場外使用事件；點卡片也會跳出選單。登場時會自動扣 AP。
        • 卡片效果、對手的防禦和 BP 比較請自己判斷。按「受到 1 傷害」會翻開生命區的卡做觸發確認。
        • 按錯了可以按「復原」退回上一步。
        算總價（三種算法）
        • 全部取最低：每張卡挑最便宜的店，湊齊整副大概要多少。
        • 全部取最高：每張卡挑最貴的店，看最多要準備多少。
        • 各店分開算：整副都在同一家買，各家要多少；會標出哪家缺哪幾種、哪些售完。
        分享與搬卡組
        • 複製清單：複製文字清單，可以直接貼到 LINE。
        • 顯示圖片：開新分頁顯示卡組圖片，手機長按圖片就能儲存或分享。
        • 複製卡組代碼 ／ 貼上代碼匯入：把卡組搬到另一台裝置，或傳給朋友直接匯入。
        • 卡組只存在你現在用的這個瀏覽器裡。清除瀏覽器資料或換手機會不見，重要的卡組記得用代碼備份。
        加到手機主畫面
        • iPhone（Safari 或 Chrome）：按「分享」→「加入主畫面」。
        • Android（Chrome）：按右上角 ⋮ →「加到主畫面」。
        • 之後點主畫面上的圖示，就會像 App 一樣直接打開。
        更新價格（管理用電腦）
        • 擴充功能：按 Chrome 工具列的查價之境圖示 → 勾選店家 →「開始匯入」，跑完會自動同步到手機。
        • 書籤：在店家網站按書籤「UA 匯入價格」→「匯入全部系列」，或在某個系列頁選「只匯入這個系列」。
        • 有新作品時勾「官方卡表（顏色・費用）」，只會抓還沒抓過的作品。
        • 建議一週最多更新一次；ドラゴンスター 要確定沒被封鎖再勾。詳細步驟在「匯入・設定」分頁。
